## Version Control

This project uses Git with GitHub (BenTheWin/ClaudeTest, private). After meaningful changes, commit and push:

```bash
git add <files>
git commit -m "concise description of what changed and why"
git push
```

Commit messages should be clear and descriptive — explain *why*, not just *what*.
